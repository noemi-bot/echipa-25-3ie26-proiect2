## Tehnologii Utilizate
* **Frontend:** React.js, Tailwind CSS.
* **Backend:** Strapi v5 (Headless CMS).
* **Găzduire:** Netlify / Vercel.
* **Formulare:** Web3Forms.
* **Tipografie:** Fonturi integrate via TweakCN (Inter, Merriweather, Fira Code).
