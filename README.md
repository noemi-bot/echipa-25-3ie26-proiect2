# Proiect Echipa 25 - Informatică Economică

## Membri: Noemi Maugeri, Cristina Chirila, Larisa Ciuboaru, Cristiana Drughi

### Tehnologii utilizate:
- **Frontend:** React.js, Tailwind CSS (configurat cu Tweakcn).
- **Backend/CMS:** Strapi Headless CMS (Single Types).
- **Hosting:** Netlify.

### Descriere:
Platformă web academică dezvoltată pentru gestiunea portofoliului echipei și automatizarea proceselor de business prin integrarea agenților inteligenți. Designul este complet responsive, implementează suport pentru Dark Mode și utilizează un sistem tipografic complex conform standardelor web moderne.
